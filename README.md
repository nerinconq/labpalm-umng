# LabPalm-UMNG · Guía de conexión

Guía en 3D para conectar el sensor a la tarjeta ESP32-S3 del proyecto «Laboratorio en la
Palma de la Mano» (Universidad Militar Nueva Granada). Paso a paso, cada cable se dibuja
sobre la placa; al final entrega el código que abre las etapas del sensor en la tarjeta
LabPalm-UMNG.

**Abrir la guía:** https://nerinconq.github.io/labpalm-umng/

Sensores: distancia (VI5300), masa (NAU7802 con celda de carga) y ángulo (AS5600).
